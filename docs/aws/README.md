# AWS deployment evidence

Place your screenshots here and reference them in the main [README.md](../../README.md) under **AWS deployment evidence**.

Suggested filenames:
- `01-server-running.png` — EC2 terminal with the server running
- `02-browser-root.png` — Browser showing `http://<IP>:35000/`
- `03-optional.png` — Security group, other evidence (optional)

Then in the main README, uncomment and edit the image lines, e.g.:

```markdown
![Server running on EC2](docs/aws/01-server-running.png)
```
